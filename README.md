# Frostfall Survivors

[브라우저에서 플레이](https://kangyunsik.github.io/like-vampire/) · WebGL 2를 지원하는 데스크톱 브라우저용

데스크톱 브라우저용 3D 생존 로그라이트입니다. 시작 화면에서 **냉기 마법사 루미** 또는 **화염 마법사 붉은 후드**를 고릅니다. 주문 하나로 시작해 레벨업 때 자동 주문을 새로 배우거나 능력을 강화합니다. 10개 스테이지의 50개 웨이브를 **30분** 동안 버티면 승리합니다.

두 특성은 `public/art/`의 서로 다른 게임용 3D 모델을 사용합니다. [루미의 망토 수정 전후](docs/lumi-cape-before-after.webp) · [붉은 후드 게임 화면](docs/fire-mage-preview.png) · [루미 초기 디자인 시안](docs/lumi-gothic-face-concept.png).

## 실행

Node.js 22.12+와 WebGL 2를 지원하는 데스크톱 브라우저가 필요합니다.

```sh
npm ci
npm run dev
```

브라우저에서 [`http://localhost:5173`](http://localhost:5173)을 여세요. 배포본 확인은 `npm run build` 후 `npm run preview -- --host 127.0.0.1 --port 4180 --strictPort`로 실행하세요. 프리뷰는 `dist/`만 읽으므로 소스 수정이나 개발 서버의 자동 새로고침에 영향받지 않습니다. 단, 같은 `dist/`를 다시 빌드하면 프리뷰도 변경됩니다. 포트가 다르면 브라우저 저장 데이터도 별도입니다.

같은 LAN에서 접속하려면 `npm run dev -- --host <맥의 LAN IP> --port 5173 --strictPort`로 실행한 뒤 다른 기기에서 `http://<맥의 LAN IP>:5173`을 여세요.

`main`에 푸시하면 [GitHub Actions](.github/workflows/deploy-pages.yml)가 Node.js 24로 빌드한 `dist/`를 GitHub Pages에 배포합니다. 같은 워크플로를 Actions 탭에서 수동으로 실행할 수도 있습니다. [정적 배포·에셋 권리·광고 출시 체크리스트](docs/deployment-review.md) · [라이브러리와 폰트 라이선스](public/third-party-notices.txt)

### 후반 스테이지 바로 테스트

```sh
npm run dev -- --open '/?stage=8&build=chain'
```

개발 서버가 이미 켜져 있다면 [`http://localhost:5173/?stage=8&build=chain`](http://localhost:5173/?stage=8&build=chain)을 여세요. **냉기 마법사**를 고른 뒤 **테스트 시작**을 누르면 체인 라이트닝과 서리 사슬을 강화한 상태로 8스테이지의 첫 웨이브(21:00)부터 시작합니다. `stage`는 1–10, `build=chain`은 냉기 2–10스테이지 전용입니다. `build`를 빼면 선택한 특성의 균형 세팅으로 시작합니다.

실제 웨이브와 보스가 이어지며 `T`로 피해 집계를 볼 수 있습니다. 저장된 영구 강화는 적용하지 않고, 최고 기록과 강화 포인트도 저장하지 않습니다. 일반 모험으로 돌아가려면 주소에서 `?` 뒤를 지우세요. 배포본과 `npm run preview`에서는 이 옵션을 무시합니다.

처음에는 냉기의 **얼음 화살** 또는 화염의 **화염구**만 사용할 수 있습니다. 레벨 **5·10·15·20…**에 새 주문을 하나 고르고, 그 사이 레벨에는 배운 주문이나 공통 능력을 강화합니다. **레어·에픽·유니크**는 각각 레벨 **10·15·20**에서 처음 열리고, 해당 레벨에서는 그 등급이 한 장 이상 제시됩니다. 배우지 않은 주문 전용 강화는 나오지 않습니다. 모험 중 마법 도감에는 시작 주문과 이번 판에 배운 주문만 획득 순서대로 나옵니다.

| 등급 | 냉기 신규 주문 | 화염 신규 주문 |
| --- | --- | --- |
| 레어 | 서리 사슬, 얼음꽃, 서리 쐐기, 결빙 낙인, 서리 돌풍 | 잿불 부채, 인화점, 불씨 표식, 용광 낙인 |
| 에픽 | 백야 폭풍, 서리달, 빙하 장벽, 극광 낙뢰 | 불사조 비행, 홍련 운석, 잿불 소용돌이 |
| 유니크 | 절대 영도, 빙하 붕괴, 체인 라이트닝 | 홍련 초신성, 용광의 심장 |

### 냉기 마법사

- **혹한의 표식:** 냉기 주문 치명타는 대상에게 **2초간 60% 둔화**를 줍니다. **4초 안에 같은 대상**에게 다시 치명타를 내면 추가 피해 없이 **1초 빙결**합니다. 이 빙결은 대상마다 8초에 한 번 발동하며, 기존 상태이상 지속시간 강화와 보스 빙결 저항이 적용됩니다.

- **얼음 회오리**: 적이 가까워지면 자동 빙결.
- **얼음창**: 빙결된 적을 우선 겨냥해 자동 관통 공격.
- **눈보라**: 사거리 안에서 적이 모인 곳을 자동 조준.
- **점멸**: 위험한 적이 다가오면 더 안전한 방향으로 자동 회피. 평상시에는 사용하지 않음.
- **얼음 보호막**: 피해를 받기 직전에 발동. 최대 6초 동안 36의 피해를 흡수하고, 활성화 중 주변 적을 주기적으로 둔화.
- **얼어붙은 구슬**: 주변 적에게 반복 피해와 감속을 줍니다. 피해를 입힌 적마다 그 구슬의 크기와 타격 반경이 기본값의 4%씩, 최대 60%까지 커집니다.
- **고드름 낙하**: 가까운 적 최대 3명을 따라 고드름이 떨어져 범위 피해.
- **결빙 낙인**: 3.6초마다 둔화된 적을 빙결하고, 돌진 준비 중인 보스를 우선합니다. **서리 전이**는 주변 둔화 대상에게 짧게 빙결을 옮기고, **낙인 회수**는 2.5초 안에 주 대상을 처치하면 남은 쿨타임을 줄입니다.
- **서리 사슬 / 서리 돌풍**: 서리 사슬은 가까운 적 무리를 우선해 타격하고 맞은 적 모두를 둔화시킵니다. 전이 반경은 4.4m, 매 전이 피해 감소는 8%이며, 전용 강화로 단계당 적 2명을 더 타격합니다. 서리 돌풍은 전방의 부채꼴 영역을 둔화시켜 다른 주문의 연계를 준비합니다.
- **극광 낙뢰 / 빙하 장벽**: 낙뢰는 보스·원거리 정예부터 강타합니다. 장벽은 전용 강화로 지속시간 또는 길이·두께가 커지며, 전용 피해 강화는 없습니다.
- **절대 영도 / 체인 라이트닝**: 절대 영도는 차가운 적을 더 강하게 타격하되 둔화·빙결을 유지합니다. 체인 라이트닝은 기본 피해 **116**, 기본 쿨타임 13초입니다. 첫 명중 후 **0.055초 간격**으로 서로 다른 적에게 최대 10회 전이하며, 전이마다 피해가 10% 줄어듭니다. 비슷한 거리라면 둔화·빙결된 적을 우선해 상태를 소모하고 2배 피해를 줍니다. 습득 후 다른 주문이 치명타를 내면 **전하 충전**을 얻습니다. 전하는 중첩되지 않으며 다음 체인 라이트닝의 첫 타격과 모든 전이 피해를 **20%** 높입니다. 전용 강화로 전이 횟수 +2(최대 +6), 전이 피해 감소율 −2%p(최소 0%), 소모 배율 +0.5(최대 3배)가 적용됩니다.
- **연계 강화**: 얼음 화살과 눈보라의 둔화율은 각각 4%p씩 강화(최대 85%). 빙결 파쇄는 빙결된 적에 대한 냉기 피해를 랭크당 기본 피해의 12%씩 추가.

### 화염 마법사

- **화염구 / 화염 작렬**: 연속 치명타 두 번으로 `몰아치는 열기`가 켜집니다. 화염 작렬의 주 대상은 항상 치명타입니다. 준비 상태는 주문 칸과 루미 주변 불꽃으로 표시됩니다.
- **불덩이 작렬**: 별도 쿨타임 없이 몰아치는 열기를 소모해 전방에 불덩이를 날립니다. 열기가 다시 차고 시전 동작이 끝나면 또 발사할 수 있습니다.
- **점화(작열)**: 해당 화염 주문이 입힌 피해의 35%가 기본 3.2초에 걸쳐 남고, 추가 적중은 잔여량을 누적합니다. 인화점·살아있는 폭탄은 남은 작열을 터뜨리고, 홍련 초신성은 강한 직접 피해에 소모한 작열의 일부를 더합니다. 용광의 심장은 불꽃 파동을 일으킨 뒤 새로 남기는 작열을 기본 6초 동안 65% 강화합니다. 용광의 심장을 배운 뒤 **타오르는 심장**을 고르면 증폭 시간이 단계당 기본 지속시간의 10%(0.6초)씩 늘어납니다. 주문별 작열 강화는 해당 주문이 남기는 작열을 랭크당 16%씩 높입니다.
- **불기둥 / 살아있는 폭탄**: 불기둥은 강한 즉발 피해와 약한 잔불을 남깁니다. 두 주문 모두 전용 반경 강화가 있습니다. **전이하는 폭탄** 1단계에서는 폭발 반경에 살아남은, 폭탄이 없는 적 **각각에게 10%** 확률을 굴리므로 한 번에 여러 적에게 붙을 수 있습니다. 5단계 50%, 10단계 75%입니다. 여러 갈래로 갈라지면 위력이 나뉘고 이후 전이에서 점차 줄어듭니다. 위력이 6% 미만이면 폭발하되 더 퍼지지 않으며, 고정된 연쇄 횟수 제한은 없습니다. 약한 전이 폭탄은 위력만큼만 작열을 소모하고 새 작열은 남기지 않습니다. 원본 폭탄의 피해는 그대로입니다.
- **불씨 표식 / 용광 낙인 / 잿불 소용돌이**: 불씨 표식은 아직 타지 않는 적부터 최대 5명에게 새 작열을 남깁니다. 용광 낙인은 작열 중인 적 최대 3명에게 즉발 피해를 주고 기존 작열 틱을 0.4초 간격으로 앞당깁니다(기존 작열량과 원래 주문의 집계는 유지). 잿불 소용돌이는 4.2초 동안 시전자를 따라 움직이며 전방을 공격합니다.
- **타오르는 방벽**: 6초 동안 최대 54 피해를 흡수합니다. 흡수 직후 1.35초간 후속 타격을 막습니다. 기본 쿨타임은 12초이며, 방벽의 불꽃 피해량은 바뀌지 않았습니다.
- **발화 / 타오르는 방벽 / 점멸**: 위험할 때 치명타를 보장하거나 피해를 막고 회피합니다. 타오르는 방벽은 활성화 중 주변 피해와 작열을 주며, 그 피해를 랭크당 18% 강화할 수 있습니다.

두 직업 모두 레벨업으로 **치명타 확률 +2%p · 치명타 피해 배율 +5%p · 경험치 +2% · 범위 반경 +8%**를 올릴 수 있습니다. 레벨업 피해 강화는 **전체 주문 +3%** 또는 개별 주문 +18%입니다. 피해와 범위 강화는 모험 중 횟수 제한이 없고, 치명타 확률 자체는 100%가 상한입니다.

기본으로 **10초마다 체력 1**을 회복합니다. 공용 특성 **빠른 재생**은 한 단계당 주기를 1초 줄이며, 최소 1초까지 줄일 수 있습니다. **잔류하는 마력**은 적에게 거는 빙결·둔화·작열 지속시간을 단계당 1초, 최대 5초까지 늘립니다. 작열은 늘어난 시간에도 피해를 계속 입히고, 보스의 빙결 저항은 그대로 적용됩니다.
공용 특성 **시간의 균열**은 단계당 자동 주문 쿨타임을 **4%** 줄이며, 최대 3단계까지 강화할 수 있습니다.

경험치 구슬은 **민트색 일반(3~11 XP) / 보라색 정예(7~22 XP) / 금빛 보스(85~920 XP)**로 구분됩니다. 보스 구슬은 가장 크고 빛기둥이 있어 멀리서도 찾을 수 있습니다.

플레이 가능한 전장은 **960×720**입니다. 북쪽과 남쪽, 서쪽과 동쪽이 끊김 없이 이어져 플레이어가 순간이동하지 않습니다. `M` 지도는 항상 내 위치를 중앙에 두며, 표시되는 방향과 거리는 이어진 쪽까지 고려합니다. 설원 곳곳에 야영지, 열린 석조 관문, 수정 제단과 등불 길이 있습니다. 큰 구조물 사이에는 통로를 남겼고, 몬스터는 장애물을 돌아서 추격하거나 서로를 피해 움직입니다. 웨이브 내내 몬스터가 카메라 시야 밖 여러 방향에서 주기적으로 등장합니다. 전장 하단의 나침반은 캐릭터가 바라보는 방향을 표시합니다.
한 방향으로 길게 이동하면 시야 밖의 전방·양옆에서 합류하는 몬스터 비중이 늘어납니다. 멀리 뒤처져 보이지 않는 일반 추격 몹도 개체 수를 줄이지 않고 옆으로 분산합니다. 보스·원거리 정예·퀘스트 몹과 교전 중인 적은 이 분산 대상이 아닙니다.

3분마다 **이동 없이 조명과 안개가 6초에 걸쳐 바뀌고** 새 적이 합류합니다. 전환으로 기존 적이나 구슬이 사라지지 않고, 다음 스테이지의 스폰 속도와 무리 크기가 다시 줄지 않습니다. 체력은 스테이지 전환 시 완전히 회복됩니다.

스테이지마다 5개 웨이브가 있으며, 보스는 마지막 웨이브에 등장합니다. 각 웨이브가 시작되면 주변 360°를 12개 구역으로 나눠 보통 네 마리씩 세 차례 포위 병력을 보냅니다. 카메라에 보이는 쪽은 같은 방향의 더 먼 시야 밖을 탐색합니다. 포위 병력 이후에도 스테이지와 웨이브에 따라 한 번에 2~4마리씩 웨이브가 끝날 때까지 계속 보충합니다. 스테이지 보스와 의뢰 미니보스는 이전 대비 체력이 절반이며 최종 보스는 **31,500 HP**입니다. 공격 패턴은 그대로이고 보스 처치는 필수가 아닙니다. 해당 모험에서 습득한 주문과 능력 강화는 매 판 초기화됩니다.
적이 이미 가까이 많이 몰려 있거나 스테이지가 진행될수록 다음 병력은 더 바깥에서 접근합니다. 동시에 활동하는 일반 웨이브 몬스터 상한은 192마리이며, 보스와 퀘스트 증원은 별도입니다.
후반으로 갈수록 새로 등장하는 적의 체력은 크게, 이동 속도는 조금씩 늘어납니다. 보스·의뢰 미니보스·원거리 정예는 경고가 시작될 때 플레이어가 그 시간 동안 이동할 수 있는 범위 안에 공격 지점을 잡습니다. 시간차가 있는 공격은 각 경고가 시작될 때 위치를 정합니다. 한 번 표시된 원은 따라오지 않으며, 기술명과 카운트다운 대신 바닥 표시와 경고음으로 예고합니다. 폭발 순간 원 안에 있을 때만 피해를 받습니다.
후반 보스는 공격 사이 간격이 짧아져도 경고 시간은 그대로입니다. 돌진은 바닥의 화살표로 경로를 예고한 뒤 그 경로를 따라 진행합니다. 경로 옆으로 피하거나 빙결로 끊을 수 있습니다.

전진·옆걸음·후진에는 다른 발 디딤이 적용됩니다. 시전 동작은 상체에 겹쳐지므로 이동 중에도 같은 방향을 바라본 채 주문을 쓸 수 있습니다. 효과음을 켜면 발이 닿을 때 눈 밟는 소리가 나고, 얼음 파열·화염 분출·번개 전이가 서로 다른 소리로 들립니다. 고드름·운석의 시전과 충돌음을 분리했으며, 보스·정예의 경고음이 날 때는 주문음과 발소리를 잠시 낮춥니다. 소리는 외부 다운로드 없이 브라우저의 Web Audio로 재생합니다.

## 보급품과 현장 퀘스트

**회복 하트**는 체력을 전부 채웁니다. **경험치 자석**은 획득 순간 전장에 떨어져 있던 모든 경험치 구슬을 거리에 관계없이 끌어옵니다. 하트는 1분 25초, 자석은 2분 30초부터 각각 약 2분 45초 간격으로 등장합니다. 줍지 않은 보급품은 75초 뒤 사라집니다. 화면의 방향·거리 안내나 `M` 지도로 찾을 수 있습니다.

NPC는 매 판 다른 위치에 배치됩니다. 새 의뢰를 줄 수 있는 NPC 머리 위에는 `!`, 진행 중인 의뢰를 준 NPC 머리 위에는 회색 `?`가 표시됩니다. 가까이서 `F`로 대화하고, 대화창에서 `F`를 한 번 더 눌러 의뢰를 수락합니다. 목표를 달성하면 경험치, 골드, 무작위 버프가 즉시 지급되며 완료 팝업에서 각 보상을 확인할 수 있습니다.

| 의뢰 | 목표 | 골드 |
| --- | --- | ---: |
| 설원 토벌 | 수락 후 일반 몬스터 100마리 처치 | 3 G |
| 매복 소탕 | 세 차례에 걸쳐 추가로 등장하는 매복 몬스터 18마리 처치 | 4 G |
| 흩어진 수정 | 경험치 구슬 35개 회수. 자석으로 끌어온 것도 포함 | 2 G |
| 균열의 수호자 | 전용 미니보스 **균열 수호자** 처치. 파동과 연속 낙하를 예고합니다. | 5 G |
| 잃어버린 신호 | 의뢰 지점에서 55–120m 떨어진 원정대 신호 3곳 방문 | 3 G |

버프는 **공격력 +10% / 이동 속도 +10% / 최대 체력 ×2** 중 하나이며, 전투 시간 기준으로 **3분**간 유지됩니다. 같은 버프를 다시 받으면 효과가 중첩되지 않고 지속시간이 갱신됩니다. `G`로 공용 특성을 열어 **2 G당 1단계** 강화할 수 있습니다. 골드, 특성, 버프는 이번 판에만 적용되며 영구 강화 포인트와는 별개입니다.

## 영구 강화

결과가 나올 때 완료한 스테이지마다 **10 P**를 받습니다. 2스테이지를 끝내고 쓰러지면 20 P, 전부 완료하면 100 P입니다. 1스테이지도 완료하지 않았거나 일시 정지 화면에서 모험을 포기하면 지급되지 않습니다.

시작 화면의 **영구 강화**에서 포인트를 사용합니다. 각 항목은 8단계까지 올릴 수 있으며, 항목별 비용은 **10 → 16 → 26 → 41 → 66 → … P**로 증가합니다.

| 항목 | 1단계당 효과 |
| --- | --- |
| 공격력 | 모든 공격 주문 피해 +3% |
| 스킬 쿨타임 | 모든 주문 재사용 대기시간 −2% |
| 획득 범위 | 경험치 구슬 획득 범위 +8% |
| 이동 속도 | 기본 이동 속도 +2% |
| 경험치 획득량 | 경험치 획득량 +5% (1 XP 미만 보너스는 모험 중 누적) |
| 최대 체력 | 기본 최대 체력 +5% |
| 웨이브 회복량 | 웨이브 시작 시 회복량 +15% |
| 체력 회복 주기 | 체력 1 자동 회복 주기 −0.5초 (공용 특성 포함 최소 1초) |
| 상태이상 지속시간 | 적에게 거는 상태이상 +0.5초 (공용 특성 포함 최대 +5초) |

보유 포인트와 강화 단계는 브라우저에 저장되고, 구매한 효과는 냉기·화염 마법사의 다음 모험에 공통 적용됩니다.

전투 중 `T` 또는 화면의 그래프 버튼으로 **실시간 피해 집계**를 열 수 있습니다. 실시간 집계와 결과 화면은 적의 체력을 실제로 깎은 양과 그 비중을 높은 순서로 보여줍니다. 작열 틱은 불씨를 남긴 주문에, 남은 작열을 터뜨린 피해는 폭발 주문에 집계합니다. 용광의 심장이 증폭한 작열 피해는 용광의 심장에 집계합니다.

마법사는 냉기와 화염 두 특성을 가진 한 직업입니다. [영혼술사·그림자 도적 신규 직업 기획](docs/class-design.md)

## 구성

- `src/combat.ts` — 렌더링과 분리된 전투, 스테이지 전환, 웨이브, 강화 로직
- `src/expedition.ts` / `src/expedition-ui.ts` — NPC 위치 및 퀘스트·보급품 규칙, 지도, 공용 특성
- `src/world/` — Three.js 전장, 직접 만든 3D 캐릭터 및 주문별 모션과 효과
- `src/data.ts` — 스테이지, 주문, 강화 정의
- `src/progression.ts` — 스테이지 보상과 영구 강화 가격·효과
- `src/main.ts` / `src/style.css` — 게임 UI, 입력, 저장

워크래프트와 PokéBonk 리소스는 포함하지 않았습니다. 키보드·마우스 환경을 대상으로 하며 모바일 조작은 아직 지원하지 않습니다.
절대 영도의 문양은 로컬 `~/engine`에서 만들었습니다. [전장 렌더에서 절대 영도와 두 얼음 투사체 보기](docs/frost-effect-preview.png). 문양을 다시 생성하려면 `~/engine/.venv/bin/python scripts/bake-absolute-zero.py`를 사용하세요.

게임용 모델은 냉기 `public/art/lumi-meshy.glb`와 화염 `public/art/red-hood-magician.glb`입니다. 루미는 독립 망토 뼈와 대기 모션을 사용합니다. 붉은 후드는 제공된 대기·걷기·달리기 및 시전 모션을 사용하며, 시전은 상체에만 적용해 이동 방향과 발동 타이밍을 유지합니다. `3d-models/`의 원본은 공개 저장소에 포함되지 않습니다. 원본이 로컬에 있을 때만 아래 스크립트로 게임용 모델을 다시 준비할 수 있습니다.

```sh
~/engine/.venv/bin/python scripts/prepare-lumi-rig.py 3d-models/Meshy_AI_Witch*.glb public/art/lumi-meshy.glb
~/engine/.venv/bin/python scripts/prepare-lumi-rig.py --character red-hood 3d-models/red-hood-magician.glb public/art/red-hood-magician.glb
```

공격할 때는 팔꿈치를 접었다 손목으로 지팡이를 휘두르며, 날아가는 투사체는 지팡이 끝 수정에서 출발합니다. 운석처럼 하늘에서 떨어지는 주문은 기존 방식으로 연출합니다. [얼음 화살·화염구 시전 애니메이션](docs/lumi-staff-cast.webp)

냉기 이펙트의 얼음 파편과 결정 군집은 Meshy T2.5로 생성한 경량 GLB입니다. 얼음 화살·얼음창·고드름에는 얼음 속의 결, 반사광과 갈라진 잔광이 보입니다. 절대 영도는 전방 지형을 타고 서리 균열이 퍼진 후 높낮이가 다른 결정이 솟고, 튄 파편과 낮은 안개가 가라앉습니다. GLB를 읽지 못해도 기본 형상과 지면 연출은 유지됩니다. [새 절대 영도 게임 캡처](docs/frost-absolute-zero-v2.png) · [이전 캡처](docs/frost-prismatic-preview.png)

[냉기·화염 주문별 연출과 전투 캡처](docs/spell-vfx.md). 캐릭터를 변경하면 직전 모델을 즉시 화면에서 내리고, 선택한 모델을 불러오기 전에는 다른 모델 대신 로딩 상태만 보여 줍니다.

[첫 웨이브 몬스터 `puff`의 젤리 슬라임 시안](docs/puff-slime-meshy-concept.png)을 Meshy T2.5 + N1으로 제작해 적용했습니다. `public/art/puff-slime.glb`는 1,657개 삼각형과 1K 텍스처를 담은 약 267 KiB의 인스턴스 모델입니다. 체력·이동·충돌 판정은 그대로이고 파일을 불러오지 못하면 기존 모델을 사용합니다. [게임 화면](docs/puff-slime-in-game.png) · [이전 털복숭이 시안](docs/puff-meshy-concept.png)

[Meshy 전나무·바위와 눈발, 눈가루, 적중 파편 개선](docs/winter-terrain.md). 960×720 전장의 지형 높이와 기존 충돌 위치는 그대로 유지했습니다.

밸런스 명령은 서버 없이 실제 전투 로직을 실행합니다. 시드마다 두 특성과 두 가지 강화 선택 전략을 비교합니다. `--expedition`은 NPC를 찾아가고 보급품을 수집하며, 획득한 골드로 공용 특성을 구매합니다. `--class fire --style area`로 화염 범위 빌드를, 여기에 `--unique supernova` 또는 `--unique infernoHeart`를 붙여 레벨 20에 특정 유니크를 배운 빌드를 검증할 수 있습니다. `--stage`는 위 브라우저 테스트와 같은 시작 주문·강화 세팅을 사용합니다. 여기에 화염 전용 `--bomb-focus`를 붙이면 전이 10단계의 폭탄 집중 세팅으로 바뀝니다. `--json`에는 실제 피해, 시전·직접 타격 횟수, 습득 후 분당 피해, 체인 라이트닝의 전하 충전 시전 횟수와 둔화·빙결 소모 횟수, 살아있는 폭탄의 전이 횟수가 포함됩니다.
