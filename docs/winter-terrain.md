두 시안은 Meshy `nano-banana-2-lite`, 게임 모델은 Meshy T2.5 Smart Topology + N1로 제작했습니다. 승인한 크레딧은 시안 **6**, GLB **30**, 합계 **36**입니다. 각 모델에 1K 텍스처를 내장해 다른 서버 요청 없이 로드합니다.

- 전나무는 가지 사이 빈 공간과 눈이 얹힌 비대칭 실루엣을 살렸습니다. 크기와 방향을 달리하고 기존 줄기 위치에 밑동을 맞췄습니다. 큰 바위에는 새 모델을 쓰고 작은 돌과 자갈을 섞어 반복을 줄였습니다.
- 눈밭의 결은 양축으로 반복돼도 이어집니다. 눈더미를 낮추고, 접촉 그림자 표면을 지형 높이에 맞춰 나무와 바위가 뜬 것처럼 보이지 않게 했습니다.
- 눈발은 깊이별로 서로 다른 속도로 떨어지고, 스테이지에 따라 바람이 달라집니다. 엷은 눈가루는 지면을 따라 흐릅니다. 눈가루는 지면 주문과 보스 예고보다 아래에 그려 공격 정보를 가리지 않습니다.
- 냉기 적중 파편은 떨어져 한 번 튄 뒤 잦아들고, 화염 불씨는 공기 저항을 받으며 위로 흩어집니다. 주문의 판정, 범위, 카메라와 지형 충돌 좌표는 그대로입니다.

나무와 바위는 구역별로 공유 메시에 그리며, 파일을 읽지 못한 종류만 기존 형상으로 표시합니다. 같은 카메라의 메뉴 한 프레임에서는 기존 형상 대신 Meshy 모델을 불러왔을 때 렌더 호출 **298 → 270**, 삼각형 **136,475 → 141,456**을 기록했습니다. 프레임 시간 비교는 아닙니다.
