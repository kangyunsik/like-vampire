# 냉기·화염 밸런스 검증

## 살아있는 폭탄 전이와 하위 화염 주문

제보한 판에서는 살아있는 폭탄에 집중해 피해의 **29.2%**를 기록했습니다. 그 비중을 문제로 보지는 않습니다. 다만 기존 코드는 가장 가까운 적 한 마리에게만 전이를 굴렸습니다. **폭발 범위 안에서 살아남은 적마다 독립 판정**하도록 바꾸고, 1~5단계는 +10%p, 6~10단계는 +5%p로 조정했습니다. 확률은 1단계 10%, 5단계 50%, 10단계 75%입니다.

한 폭발에서 여러 전이에 성공하면 파생 폭탄 개별 위력이 줄지만, 전이에 많이 성공할수록 다음 폭발의 총 위력은 늘어납니다. 한 번 갈라진 전이는 이후 폭발마다 약해져 위력이 6% 미만이면 폭발만 하고 새 전이를 만들지 않습니다. **직접 시전한 폭탄의 수치와 한 갈래로만 이어지는 전이는 그대로**입니다. 약한 복제는 자신이 가져간 작열만 소모하고 다른 주문의 작열을 새로 덮지 않습니다.

- **불덩이 작렬:** 별도 쿨타임을 없앴습니다. 몰아치는 열기 소모와 전방 자동 시전은 그대로입니다.
- **잿불 소용돌이:** 반경 3.8 → 5.4m, 지속 3.6 → 4.2초, 틱 간격 0.72 → 0.64초. 타는 적에도 이전보다 많은 피해를 줍니다.
- **용광 낙인:** 작열 중인 적 최대 3명을 타격하고, 그 작열의 틱을 0.4초 간격으로 앞당깁니다. 남은 작열량과 원래 주문의 피해 집계는 유지합니다.
- **불씨 표식:** 피해 24 → 42, 최대 대상 3 → 5명. 작열이 없거나 적은 대상을 우선하되 모두 타고 있어도 발동합니다.
- **인화점**에 기본 폭발 피해를 추가하고, **잿불 부채·불사조 비행·화염 작렬**은 유효 범위나 부가 타격을 소폭 올렸습니다. **타오르는 방벽**은 피해량을 유지하고 기본 흡수량 36 → 54, 쿨타임 14 → 12초, 흡수 직후 후속타 보호 0.85 → 1.35초로 방어를 보강했습니다.


`--bomb-focus`는 9스테이지부터 연쇄 강화 10단계와 폭탄 전용 피해·작열·반경 특성을 넣는 별도 스트레스 테스트입니다. 폭탄의 `casts`는 마법사가 직접 건 횟수, `transfers`는 폭발로 다른 적에게 옮겨 간 횟수입니다. 일반 모험의 습득 시점과 이동은 재현하지 않습니다.

## 후반 연쇄 주문 재조정

제보한 판에서는 체인 라이트닝과 서리 사슬이 둘 다 **5.2%**였습니다. 습득 시점과 강화 단계가 기록에 없으므로 같은 판을 재현한 수치는 아닙니다. 두 주문의 전용 특성을 올리고 8스테이지(21:00)부터 시작하는 동일 프리셋으로, 시드 `401·504·607·710`의 변경 전후를 비교했습니다. 주문별 피해는 게임의 `T` 집계와 같이 적이 실제로 잃은 체력만 셉니다.

- **체인 라이트닝:** 기본 피해 86 → 92, 대기시간 16 → 13초. 서리 사슬과 서리 돌풍 뒤에, 극광 낙뢰와 서리 쐐기보다 먼저 시전 기회를 얻습니다. 비슷한 거리의 적 중 둔화·빙결 대상을 우선하며, 증폭 피해를 준 뒤 해당 상태를 모두 소모합니다.
- **서리 사슬:** 기본 피해 36 → 50, 전이 반경 3.5 → 4.4m, 매 전이의 피해 감소 16% → 8%. 고립된 적보다 연쇄 가능한 무리에서 시작합니다. 맞은 적의 둔화, 쿨타임, 최대 타격 수는 유지합니다.
- 전방 180° 자동 시전, 얼음 회오리의 제어 역할, 빙하 장벽의 지속시간·크기 강화, 절대 영도의 피해 및 빙결 수치는 변경하지 않았습니다.

## 12방향 포위 웨이브와 살아있는 폭탄

실제 브라우저 카메라로 시작 병력이 12개 각도 구역에 걸쳐 화면 밖에서 세 차례에 나눠 생성되는지 확인했습니다. 별도의 고정 카메라 테스트에서는 첫 36초 동안 보충 병력 **58마리**를 기록했으며, 마지막 2초에도 새 적이 등장했습니다. 기존 시작 몹 4마리는 이 테스트에서 제외했습니다. 후반 또는 근처 밀집 상황에서는 보충 수를 줄이는 대신 등장 거리를 늘립니다.

살아있는 폭탄의 전이 강화는 단계당 **10%p**, 최고 10단계에서 100%입니다. 같은 적에게 다시 전이할 수 있고, 연쇄 횟수 제한은 없습니다. 변경 후 원정 보상을 사용하는 균형 빌드 소표본에서 냉기 2/2회, 화염 1/2회로 총 **3/4회** 완주했습니다. 이 시뮬레이션은 실제 브라우저 카메라를 사용하지 않습니다.

절대 영도는 빙결 3.6초를 유지하면서 기본 반경을 7.1로 늘리고, 쿨타임 26초 → 21초, 기본 피해 56 → 90(이미 둔화·빙결된 적은 135)으로 조정했습니다. 체인 라이트닝을 레벨 20에 고른 별도의 속성 연계 빌드 4회는 전부 완주했으며, 체인 라이트닝은 평균 **177,598 실제 피해, 11.7% 비중**을 기록했습니다. 서리 돌풍은 그 전에 둔화를 걸어 주고, 극광 낙뢰는 보스·원거리 정예에 피해를 집중하는 다른 선택지입니다.

### 피해가 아닌 기여

빙결은 5프레임 간격으로 살아 있는 적의 **유효 빙결 시간**을 샘플링합니다. 동시에 서로 다른 둔화가 걸리면 가장 강한 둔화만 세고 지속시간에 둔화율을 곱합니다. 피해 무효화가 비교 가능한 경우에는 보호막이 실제 흡수한 HP와 냉기로 중단한 돌진 횟수를 따로 집계합니다. 적 10명을 1초 얼리면 **10 대상·초**입니다. 점멸은 실제 피한 피해의 반사실 추정 대신 사용 횟수만 기록합니다. 주문별 유틸 통계는 변경 후 JSON의 `utilityBySpell`에 들어 있습니다.

- 눈보라 집중 빌드에서 **얼음 회오리**는 피해 비중이 2.2%였지만 평균 **3,946 대상·초**를 얼리고 돌진을 판당 1.17회 끊었습니다. 피해는 올리지 않았습니다.
- **빙하 장벽**을 배운 냉기 균형 판에서 평균 **970 대상·초** 빙결과 **1.33회** 돌진 중단이 잡혔습니다. 피해 강화 카드를 빼고 지속시간과 크기 강화로 바꿨으며, 기본 접촉 피해는 그대로입니다.
- 냉기 균형 빌드에서 **얼음 보호막**은 평균 **601 HP**를 흡수했고, **점멸**은 평균 **130회** 발동했습니다. 0 피해라고 해서 기여가 0인 주문은 아닙니다.

### 냉기와 화염

동일한 시드 4개씩, 영구 강화 없이 원정 보상·보급품을 활용하는 균형 빌드로 비교했습니다. 냉기 완주는 **3/4 → 4/4**, 화염은 **4/4 → 4/4**로 유지했습니다. 마지막 9분 평균 실제 DPS는 냉기 **1,683 → 2,628**, 화염 **2,760 → 2,760**이었습니다. 피해 격차가 줄었고 냉기는 빙결을 더 많이 활용합니다. 이 표본만으로 두 특성의 승률이 같다고 보지는 않으며, 화염 수치는 추가 변경하지 않았습니다.

```sh
npm run balance -- --seeds 6 --class frost --style blizzard --force-blizzard --expedition --json
npm run balance -- --seeds 4 --style balanced --expedition --json
npm run balance -- --seeds 4 --class frost --style elemental --unique chainLightning --expedition --json
```

## 냉기 치명타·결빙 낙인과 연결 전장

치명타는 대상별 둔화·빙결을 제공하고, 결빙 낙인은 기본 쿨타임 3.6초와 전이·회수 특성을 갖습니다. `npm run balance -- --seeds 2 --class frost --style balanced --expedition`에서 영구 강화 없이 **2/2회** 30분을 생존했습니다. 긴 이동 중 화면 밖 보강과 후방 추격 몹 분산은 카메라에 따라 결정되므로, 헤드리스 결과 대신 가시 범위를 포함한 스폰 테스트로 따로 검증합니다.

## 보스 패턴·쿨타임·전장 업데이트 이후

후반 보스의 공격 간격을 줄이고 태엽 대감시자의 둔화와 예고 돌진을 추가했습니다. 공용 쿨타임 감소는 단계당 4%이며, 몸체 충돌 반경을 적용해 몬스터가 같은 자리에 쌓이지 않도록 했습니다.

`npm run balance -- --seeds 2 --style balanced --expedition`에서 두 직업이 각 2회씩, 합계 **4/4회** 생존했습니다. 총 52건의 의뢰를 완료했으며, 미니보스와 넓어진 신호 탐색 의뢰가 각각 12건이었습니다. 이 수치는 영구 강화 없이 같은 조작 규칙을 사용한 소수 시드 결과입니다.

`npm run balance -- --seeds 3`에서 NPC를 찾아가지 않는 기본 운용은 **5/12회** 생존했습니다. 두 직업의 균형 빌드는 각각 2/3, 속성 연계 빌드는 냉기 0/3·화염 1/3이었습니다. 두 실험은 빌드와 이동 규칙이 다르며, 기본 실험에는 실제 카메라 시야와 지형 충돌이 포함되지 않습니다.

`npm run balance -- --seeds 4 --class fire --style area --json`에서는 원정 지원 없이 **1/4회** 생존했습니다. 화염구가 누적 피해 1위였던 판은 0/4회였고, 각 유니크는 네 회차 모두 자신을 습득한 이후 같은 시간 동안의 화염구 실제 피해를 넘었습니다. 전체 누적 피해 1위는 홍련 초신성 3회, 불기둥 1회였습니다.

## 이전: 30분 확장과 원거리 정예

21분 이후에 천둥 서리광장, 갈라진 성역, 여명의 왕좌를 추가했습니다. 원거리 정예는 고정된 예고 원이 터질 때만 공격 피해를 줍니다. 기존 일곱 스테이지 보스는 종전 체력의 3배이며, 새 최종 보스의 체력은 63,000입니다.

영구 강화 없이 세 시드에서 NPC를 찾아가지 않는 기본 시뮬레이션을 실행했습니다. 냉기 균형 2/3, 냉기 속성 연계 3/3, 화염 균형 3/3, 화염 속성 연계 1/3으로, 합계 **9/12회**가 30분을 생존했습니다. 시드와 빌드에 따라 퀘스트 없이 버티기 어렵습니다.

같은 전투 로직에서 NPC·보급품을 찾아가고 골드를 쓰는 균형 빌드를 두 시드씩 실행했을 때 **4/4회** 생존했습니다. 총 52건의 의뢰를 완료했고, 그중 전용 미니보스와 신호 탐색이 각각 12건이었습니다. 소수 시드의 결과이며, 두 실험의 빌드와 조작 규칙은 다릅니다.

```sh
npm run balance -- --seeds 3
npm run balance -- --seeds 2 --style balanced --expedition
```

## 21분 버전: 전장 확장 직후

960×720 전장과 스테이지 전환 후에도 유지되는 몬스터 무리 크기·스폰 속도를 적용했습니다. 보스 체력은 이전 빌드의 3배입니다. 영구 강화 없이 실행한 `npm run balance -- --seeds 6`에서는 냉기와 화염의 균형·속성 연계 빌드가 **23/24회** 21분을 생존했습니다. 한 회차는 화염 속성 연계 빌드에서 실패했습니다. 이 시뮬레이션은 NPC를 찾아가거나 골드를 쓰지 않습니다.

## 이전 업데이트: 적 성장과 화염 범위 빌드 재검증

같은 12개 시드(`401`부터 `103` 간격)로 실제 전투 로직을 실행했습니다. 영구 강화 없이 캐릭터를 적 쪽으로 직접 돌리며, 기술은 전방 180°에서 자동으로 시전합니다. **실제 피해**는 결과창과 같은 기준으로, 적이 잃은 체력만 세고 초과 피해는 제외합니다.

### 진행 난이도

스테이지가 진행될수록 새로 등장하는 적이 강해집니다. 기존과 비교해 첫 스테이지 첫 웨이브의 적은 그대로이며, 마지막 스테이지 마지막 웨이브의 일반 적은 체력이 약 **2배**, 이동 속도가 약 **14%** 높습니다. 마지막 보스 체력은 **6,400 → 9,600**입니다.

| 직업 · 빌드 | 21분 생존 | 초반 실제 DPS | 중반 실제 DPS | 후반 실제 DPS | 후반 보스 처치 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 냉기 · 균형 | 12 / 12 | 122.8 | 347.9 | 983.7 | 22 / 24 |
| 냉기 · 속성 연계 | 12 / 12 | 124.9 | 347.7 | 994.4 | 23 / 24 |
| 화염 · 균형 | 12 / 12 | 127.0 | 354.0 | 1,035.9 | 14 / 24 |
| 화염 · 속성 연계 | 12 / 12 | 126.2 | 353.8 | 1,029.8 | 16 / 24 |

구간은 0–6분, 6–15분, 15–21분입니다. 보스를 전부 처치하지 않아도 생존할 수 있습니다. 보스 경고 원의 기술명·남은 시간과 발동 효과는 실제 판정 위치와 반경을 사용하되, 공격 타이밍이나 반경은 바꾸지 않았습니다.

### 화염구 대 유니크

범위 빌드에서 화염구가 전체 누적 피해 1위였던 판은 **9/12 → 0/12**로 줄었습니다. 화염구의 주 대상 피해는 유지하고 주변 피해만 낮췄습니다. 홍련 초신성은 직접 폭발 피해를 주고 모은 작열을 일부 더하며, 용광의 심장은 더 강한 파동을 주고 자신이 증폭한 작열 피해를 직접 집계합니다.

| 주문 | 변경 전 후반 평균 피해 (시전) | 변경 후 후반 평균 피해 (시전) | 변경 후 같은 판의 화염구 피해 |
| --- | ---: | ---: | ---: |
| 화염구 | 32,118 (374.8회) | 26,848 (360.4회) | — |
| 홍련 초신성 | 19,795 (18.1회) | 75,310 (18.1회) | 26,742 |
| 용광의 심장 | 8,882 (15.2회) | 55,918 (21.0회) | 26,145 |

각 평균은 해당 주문을 배운 회차만 포함합니다. 변경 후 홍련 초신성은 11회, 용광의 심장은 9회 등장했고, 두 주문 모두 각각을 배운 모든 회차에서 후반 화염구 피해를 넘었습니다. 일반 제안을 사용한 범위 빌드는 **10/12회** 생존했고, 나머지 2회는 마지막 스테이지에서 탈락했습니다.

유니크의 등장 순서 때문에 생기는 차이도 확인했습니다. 레벨 20에 각 유니크를 고정으로 배우게 한 뒤, 그 시점부터 누적한 피해를 같은 시간대의 화염구와 비교했습니다. 레벨 25부터는 다른 유니크도 배울 수 있습니다.

| 레벨 20에 배운 주문 | 습득 후 평균 피해 | 같은 시간 화염구 피해 | 평균 시전 횟수 | 21분 생존 |
| --- | ---: | ---: | ---: | ---: |
| 홍련 초신성 | 125,562 | 62,244 | 55.6 | 11 / 12 |
| 용광의 심장 | 94,700 | 61,021 | 61.8 | 10 / 12 |

두 유니크 모두 이 비교에서 12회 전부 화염구를 넘었습니다. 이 결과는 지정된 조작·빌드의 비교이며, 사람의 승률이나 모든 판에서의 주문 순위를 보장하지 않습니다.

```sh
npm run balance -- --seeds 12
npm run balance -- --seeds 12 --class fire --style area --json
npm run balance -- --seeds 12 --class fire --style area --unique supernova --json
npm run balance -- --seeds 12 --class fire --style area --unique infernoHeart --json
```

## 이전 기록

직업별 레어 4종·에픽 3종·유니크 2종과 5레벨 간격 습득 규칙을 적용한 뒤 `npm run balance -- --seeds 12`를 다시 실행했습니다. 12개 시드 × 2직업 × 2개 빌드(기본기 중심 / 속성 연계 중심), 총 **48회**입니다. 영구 강화 없이 같은 이동 규칙을 사용했으며, 모든 회차에서 7스테이지를 생존했습니다. 스테이지 보스 처치는 생존 조건이 아니므로 별도로 집계했습니다.

| 구간 | 냉기 평균 DPS | 화염 평균 DPS | 냉기 보스 처치 | 화염 보스 처치 |
| --- | ---: | ---: | ---: | ---: |
| 초반 0–6분 | 155.3 | 149.7 | 48 / 48 | 48 / 48 |
| 중반 6–15분 | 331.4 | 324.5 | 71 / 72 | 72 / 72 |
| 후반 15–21분 | 696.3 | 692.2 | 30 / 48 | 36 / 48 |

- **초반:** 레벨 2–4에 기본 주문을 강화한 뒤 레벨 5에 두 번째 주문을 배웁니다. 더 느린 습득 간격에서도 두 직업의 초반 보스 처치는 모두 성공했습니다.
- **중반:** 두 직업의 처치 속도는 분당 약 114마리로 비슷했습니다. 냉기는 둔화와 빙결, 화염은 범위와 작열로 적 무리를 처리합니다.
- **후반:** 평균 피해량은 두 직업이 비슷했지만, 화염은 보스 처치가 더 많고 피격 체력 손실도 더 컸습니다. 화염의 작열 틱은 두 빌드에서 평균 약 **61 DPS**였습니다.

이전 표의 DPS는 타격 및 작열 수치의 합계이며, 초과 피해를 포함합니다. 이 결과는 사람의 조작 난이도나 승률을 추정한 것이 아니라, 같은 움직임과 강화 규칙을 준 전투 시뮬레이션 결과입니다.

전방 180° 조준과 지팡이 투사체의 짧은 준비 동작을 추가한 뒤에는 `npm run balance -- --seeds 6`으로 다시 검증했습니다. 테스트 조작이 실제 방향 전환 속도로 적을 보도록 했고, 두 직업·두 빌드의 24회 모두 21분을 생존했습니다.
