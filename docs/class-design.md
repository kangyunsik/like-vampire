# 신규 직업 기획

현재 **마법사**가 한 직업이고 **냉기·화염**은 그 안의 특성입니다. 이번에는 아래 두 직업의 기획만 작성했습니다. 공통 규칙은 전방 조준, 자동 기본 공격, 5레벨 간격의 신규 능력 선택입니다. 직업별 자원은 HUD에서 확인하게 하고, 기존 영구 강화와 퀘스트 보상은 각 직업이 동일하게 사용하게 합니다.

| 직업 | 핵심 자원 | 전투 감각 | 추천 특성 |
| --- | --- | --- | --- |
| 영혼술사 | 처치와 주기적 흡수로 얻는 영혼 | 광역 처리 후 자원을 모아 소환 또는 보호에 사용 | 망령 지휘 / 영혼 포식 |
| 그림자 도적 | 가까운 적에게 공격을 이어 얻는 연계점수 | 보스의 경고를 피해 들어가고, 짧은 틈에 마무리 | 기습 / 검무 |

## 1. 영혼술사 — 처치가 다음 무리를 무너뜨린다

- **자원:** 일반 적 처치 시 영혼 1개, 정예는 2개, 보스는 4개. 기본 보유 상한은 12개. 보스 한 마리만 상대하는 상황에도 자원이 모이도록, 첫 적을 맞히는 기본기 **혼불**이 일정 간격으로 영혼을 하나 만듭니다. 영혼은 직업 자원이며 XP·골드와 분리됩니다.
- **망령 지휘:** 영혼 4개를 쓰면 전방에서 싸우는 망령을 잠시 부릅니다. 망령 수를 제한하고, 같은 자리에서 중복 소환하면 수명만 갱신합니다. 레어 **잔향 이식**은 망령이 대상을 바꾸면 한 번에 새 적을 더 묶고, 에픽 **혼의 대열**은 여러 망령이 정예에게 공격을 집중하게 합니다.
- **영혼 포식:** 위험할 때 영혼 3개로 짧은 보호막을 얻거나, 모아 둔 영혼으로 전방을 폭발시킵니다. 유니크 **저승의 문**은 영혼 8개를 쓰는 큰 광역 공격이지만, 문 자체의 처치로는 영혼을 돌려받지 않아 무한 연쇄를 막습니다.
- **약점:** 영혼이 적을 때는 주문 폭발력이 작고, 범위 바깥 적을 따라 이동해야 합니다. 소환 특성은 혼불 추출 덕분에 보스에서 무력해지지 않지만, 단일 대상 공격력이 과도하게 높아지지 않도록 묶습니다.
- **먼저 만들 것:** 혼불 → 영혼 획득/상한 HUD → 망령 소환 1종 → 영혼 보호막. 이후 시뮬레이션에서 초반 자원 부족 시간, 후반 자원 넘침 빈도, 보스전 소모 횟수를 확인합니다.

## 2. 그림자 도적 — 연계점수와 안전한 공격 타이밍

- **자원:** 전방 근접 공격 **재빠른 찌르기**로 연계점수를 1점씩 얻고 최대 5점을 보유합니다. 점수는 적이 아니라 플레이어에 쌓여, 일반 적이 빨리 죽어도 다음 적에게 쓸 수 있습니다. 반대편까지 무조건 추격하거나 자동으로 방향을 틀지 않습니다.
- **기습:** 적의 후방에서 찌르면 일정 간격으로 점수 1점을 더 얻습니다. 에픽 **그림자 걸음**은 예고 원에 자동으로 들어가지 않고, 플레이어가 고른 이동 방향으로만 짧게 회피합니다. 5점 **일격**은 보스·정예를 우선하는 큰 단일 피해입니다.
- **검무:** 짧은 관통 공격으로 최대 세 적을 긋되 한 시전에 얻는 점수는 상한을 둡니다. 점수 3점 **부채칼**은 무리 처리, 5점 **칼날의 춤**은 짧은 연속 공격입니다. 둘 다 시전 당시 전방을 유지합니다.
- **조작과 약점:** 기본은 현 게임처럼 자동으로 연결합니다. 얼어붙은 적이나 돌진 후 빈틈을 노리게 하되, 원거리에서 계속 딜을 넣는 마법사보다 사거리가 짧습니다. 소모기를 아끼고 싶을 때의 수동 저장 기능은 기본형을 검증한 뒤 검토합니다.
- **먼저 만들 것:** 재빠른 찌르기 → 5칸 HUD → 단일·범위 소모기 → 입력 기반 회피. 평균 점수 낭비, 보스 공격을 피해 들어갔다 나올 수 있는 시간, 근접 피격량을 측정합니다.

**추천 순서:** 영혼술사를 먼저 구현합니다. 기존 자동 전투와 몬스터 무리·정예 처치 흐름을 그대로 활용해 자원 경제를 먼저 검증할 수 있습니다. 도적은 그다음에 근접 조준과 보스 경고 회피가 충분히 읽히는지 확인하며 구현하는 편이 좋습니다.
