# 냉기·화염 주문 이펙트

판정·범위·쿨타임은 그대로입니다. 냉기는 각진 결정, 가느다란 바람 결, 푸르고 보랏빛인 반사광으로 표현했습니다. 화염은 어두운 탄 흔적, 주황색 열맥, 밝은 불의 심지로 읽히게 했습니다. 진행 방향과 공격 범위를 보여 주되, 주문의 지면 연출은 보스 경고보다 아래에 그립니다.

| 냉기 주문 | 전투에서 보이는 모습 |
| --- | --- |
| 얼음 화살 · 얼음창 | 작은 서리별과 결정 잔광 / 길게 뻗는 보랏빛 창과 빙결 명중 시 파열 |
| 얼음 회오리 · 눈보라 · 백야 폭풍 | 낮게 번지는 육각 서리 / 비스듬히 내리는 눈 / 보랏빛 소용돌이 위로 올라오는 결정 |
| 얼음 보호막 | 반투명 얼음 판과 천천히 교차하는 테두리 |
| 점멸 | 출발지와 도착지의 얇은 문, 사이에 남는 휘어진 잔광. 화염 특성에서는 열색으로 변합니다. |
| 얼어붙은 구슬 · 고드름 낙하 | 결정 핵을 비스듬히 감싸는 두 궤도 / 낙하 궤적과 착지점에서 튀는 파편 |
| 서리 사슬 · 서리 쐐기 · 결빙 낙인 · 서리 돌풍 | 굽어진 얼음 연결선 / 세 갈래 궤적 / 적에게 겹치는 육각 봉인 / 지면 가까이 지나가는 바람 줄기 |
| 얼음꽃 · 빙하 장벽 · 서리달 | 주위로 펼쳐지는 결정 꽃잎 / 지면 높낮이에 맞춰 이어지는 얼음 벽 / 잔상과 함께 내려오는 초승달 |
| 극광 낙뢰 · 체인 라이트닝 | 높은 곳에서 갈라져 내려오는 민트빛 낙뢰 / 보랏빛 전기가 적 사이에서 차례로 갈라지는 연쇄 |
| 절대 영도 · 빙하 붕괴 | 지형을 타고 퍼지는 균열, 솟는 결정과 안개 / 안쪽으로 말려들며 깨지는 결정과 파편 |

| 화염 주문 | 전투에서 보이는 모습 |
| --- | --- |
| 화염구 · 화염 작렬 · 불덩이 작렬 | 달궈진 심지와 가느다란 불길 / 한 지점으로 꽂히는 짧은 열섬광 / 더 큰 불덩이가 남기는 충격 자국 |
| 불기둥 · 홍련 운석 | 엇갈려 위로 솟는 불꽃과 잔열 / 녹은 암석이 떨어져 생기는 분화구, 튀는 돌조각과 재 |
| 살아있는 폭탄 · 불씨 표식 · 용광 낙인 | 시간이 가까워질수록 흔들리는 표기 / 여러 적에게 남는 작은 마름모 / 적 위에서 도는 금빛 인장 |
| 발화 · 타오르는 방벽 | 몸에 감겨 올라오는 불길 / 겹치는 뜨거운 비늘과 주위를 도는 불꽃 띠 |
| 잿불 부채 · 잿불 소용돌이 | 앞쪽으로 찢어지듯 흐르는 불길 / 이동 방향 쪽에서 도는 불씨 띠 |
| 인화점 · 불사조 비행 | 한 지점에 모였다가 터지는 불꽃 / 흔들리는 불깃과 양쪽 날개에서 갈라지는 꼬리 |
| 홍련 초신성 · 용광의 심장 | 어두운 핵을 도는 불꽃과 바깥으로 퍼지는 충격파 / 박동을 따라 겹쳐 나가는 열 파동과 남은 심장 |

얼음 파편과 결정 군집은 기존 Meshy GLB를 사용합니다. 불꽃·용암·서리 문양·잔광은 게임 렌더러에서 만들었으며 주문 전용 새 모델은 생성하지 않았습니다. 공통 적중 파편은 냉기와 화염의 움직임을 나눴습니다. 냉기 파편은 땅에 닿아 튀고 가라앉으며, 화염 불씨는 공기 저항을 받으며 올라갑니다. [지형과 환경 이펙트](winter-terrain.md)
